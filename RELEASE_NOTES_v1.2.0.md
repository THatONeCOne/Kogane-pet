Kogane Pet v1.2.0

- Added automatic checks for new versions from the public GitHub releases page.
- Added a red update badge to Settings in the radial wheel when a newer version is available.
- Added release notes, download, SHA-256 verification, installation and automatic restart in Settings.
- The updater preserves the user's local settings.json file.
- Updated settings and changelog information.

This is the first release with the updater. Existing installations must install this version once; later releases can be installed from inside Kogane.
