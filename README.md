# Kogane Pet

Kogane Pet is a small Windows desktop companion.

## Download and install

1. Open the [latest release](https://github.com/THatONeCOne/Kogane-pet/releases/latest).
2. Download `KoganePet-Windows.zip` and extract it.
3. Open `share-KoganePet` and run `KoganePet.exe`.

The first updater-enabled version must be installed once from a release ZIP. After that, Kogane checks for newer releases and can download and install them from Settings.

Release packages do not include personal settings files.
